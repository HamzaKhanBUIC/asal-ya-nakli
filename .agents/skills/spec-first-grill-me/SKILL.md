# The Spec-First & Grill-Me Habit

## Guidelines
1. Before writing feature code, prompt the user for a 1-paragraph summary of what is being built.
2. Ask 3-5 high-impact questions to resolve edge cases, data flows, and design intent.
3. Lock down a clear `build_spec.md` or feature contract.
4. Execute strictly against the approved spec.

# Frontend Design Taste & Visual Guardrails

## Core Principles
1. **Utility-Driven Aesthetics**: Clean layout, clear visual hierarchy, accessible contrast.
2. **Modern Typography**: Curated Google Fonts, crisp letter-spacing and line-heights.
3. **Harmonious Color Systems**: HSL/CSS custom property palettes (dark/light neutral tones, elegant accents).
4. **Fluid Micro-Interactions**: Smooth hover effects, dynamic transitions, interactive states.

## Anti-Pattern Rules (Forbidden Tropes)
- ❌ No purple fonts on dark theme backgrounds.
- ❌ No colored border accents or glowing outlines.
- ❌ No un-tracked huge headlines.
- ❌ No textureless/flat boring containers.
- ❌ No icon-stuffed bento boxes without purpose.
- ❌ No headline biscuit pills with pulsing dots unless requested.
- ❌ No rainbow CSS gradient keyword fills.

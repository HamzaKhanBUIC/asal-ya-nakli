# The Hamza Method: Expert AI Workflow

## Core Execution Steps
1. **Spec Alignment**: Write explicit specifications for the target feature/app.
2. **Mockups & Concept**: Define visual components and UI hierarchy up front.
3. **Build Spec Generation**: Maintain a structured `build_spec.md`.
4. **Project Log**: Track progress iteratively in `Project Log.md`.
5. **Phase-by-Phase Execution**: Test thoroughly between build phases to prevent compound bugs.
6. **Sanity Verification**: Validate code architecture against best practices before proceeding to the next milestone.

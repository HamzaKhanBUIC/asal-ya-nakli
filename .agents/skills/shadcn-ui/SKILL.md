# Shadcn UI & Component Architecture

## Guidelines
1. **Reusable Primitives**: Build small, decoupled UI components using standard Radix/Shadcn primitives.
2. **Design Tokens**: Standardize colors, spacing, radius, and shadows via CSS variables or utility classes.
3. **Accessibility**: Ensure full keyboard navigation, proper ARIA roles, and focus-visible rings.
4. **Composition**: Favor composition over monolithic components.
